# ⚡ Cambridge IGCSE Physics Paper 2 (MCQ) Auto-Grader

An AI-powered auto-correction tool for Cambridge IGCSE Physics 0625 Paper 2 (Multiple Choice).

## Features
- **46 Pre-loaded Exams (2020–2026):** All variants (V1, V2, V3) and sessions (March, June, November).
- **Supports 3 Input Formats:**
  1. Circled / marked exam question papers
  2. Bubble / OMR answer sheets
  3. Handwritten notebook pages (e.g. *1. B, 2. A, 3. C...*)
- **Instant Results (< 5 seconds):** Total mark out of 40, percentage score, estimated Cambridge grade (A* to U), and itemized error review.
- **Secure Teacher Portal:** Protected behind a PIN so students never see class records.

## Deployment
Built with [Streamlit](https://streamlit.io) and [Google Gemini Vision](https://ai.google.dev).
